# Dataset attribution

This project uses the UCI Machine Learning Repository's **Thyroid Disease** dataset:

> Quinlan, R. (1986). *Thyroid Disease* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5D010

The dataset is distributed under the Creative Commons Attribution 4.0 International license. The raw files are included unchanged for reproducibility. They contain anonymized clinical attributes and record identifiers supplied by the dataset publisher, not personal data collected by this project.

Source: https://archive.ics.uci.edu/dataset/102/thyroid+disease
